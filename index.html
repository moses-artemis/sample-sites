Sample sites

I built these from public files only. Each product is a single-page app, so the browser already downloads its HTML, CSS, and JavaScript before anyone signs in. I rebuilt the screens from those files. No source code, and no logged-in account.

7AI and Vega include the signed-in layout in that public JavaScript, so those samples can be clicked through. Where a screen had the design but no rows, I filled in sample data and labeled it. It is not a real tenant.

Artemis is the one that keeps the product private. The signed-in app is not in the public files. The Artemis pages here are the only ones a visitor can open without logging in.

  • Vega Public app layout. Rows are sample data, not a real tenant.
  • Artemis Only the pages visible without login. The signed-in app is not in the public files.
